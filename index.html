Sync across your devices

Pick a private passcode. Every device where you enter the same passcode shares the same grades, notes, flashcards, assignments and study time — live. Your API key never leaves this device.

Treat the passcode like a password. Anyone who knows it can read your study data. Use something long that you don't use elsewhere.

One-time Firebase setup (if sync fails)

In Firebase Console → Realtime Database → Rules, make sure the studypro path is allowed. If your rules are already fully open (as they are for the soccer scores) nothing to do. Otherwise paste:

{
  "rules": {
    "matches":  { ".read": true, ".write": true },
    "studypro": { "$id": { ".read": true, ".write": true } }
  }
}
